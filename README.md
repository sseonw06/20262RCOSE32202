# 20262RCOSE32202

운영체제 수업에서 배운 프로세스와 IPC 개념을 복습하기 위한 C 예제 코드입니다.
AI(Claude)의 도움을 받아 코드를 작성했고, 코드를 읽으면서 각 개념이 어떻게 동작하는지 공부했습니다.

## 예제 목록
- `01_fork.c`: fork()로 자식 프로세스를 만들고 wait()로 종료를 기다림
- `02_pipe.c`: 파이프로 부모 → 자식 프로세스에 문자열 전달

Linux에서 `gcc 파일명.c`로 컴파일할 수 있습니다.

## 공부한 내용
- fork()는 한 번 호출되지만 부모와 자식에서 각각 반환된다.
- fork() 반환값은 자식에게 0, 부모에게 자식의 PID이다.
- 자식은 부모의 메모리를 복사해 받으므로 한쪽에서 변수를 바꿔도 다른 쪽에는 영향이 없다.
