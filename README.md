## 예제 목록
- `01_fork.c`: fork()로 child process를 만들고 wait()로 종료를 기다림
- `02_pipe.c`: 파이프로 parent → child process에 문자열 전달

## 개념
- fork()는 한 번 호출되지만 부모와 자식에서 각각 반환
- fork() 반환값은 자식에게 0, 부모에게 자식의 PID
- 자식은 부모의 메모리를 복사해 받음
- 부모가 wait()로 자식을 회수해야함
- pipe()는 읽기용 fd[0]과 쓰기용 fd[1]을 만들고, 단방향으로만 데이터가 흐름
- 쓰는 쪽을 close()해야 읽는 쪽이 EOF를 받고 read()가 끝남
